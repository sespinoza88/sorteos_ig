Política de privacidad

Última actualización: 14 de octubre de 2026

Sorteos App ("la app") permite realizar sorteos entre las personas que comentaron una publicación o reel de tu cuenta de Instagram.

Datos a los que accede la app

  • Tu token de acceso de Instagram, obtenido cuando inicias sesión con Instagram.
  • La lista de tus publicaciones (identificador, descripción, miniatura y enlace).
  • Los comentarios de la publicación que eliges (nombre de usuario, texto y fecha).

Cómo se usan

Los datos se usan únicamente para mostrar los comentarios, aplicar los filtros del sorteo y elegir a los ganadores. No se usan para publicidad ni para crear perfiles.

Almacenamiento y terceros

La app no tiene servidores propios. El token se guarda cifrado en tu dispositivo y los comentarios se procesan solo en la memoria del dispositivo. No vendemos, compartimos ni transferimos datos a terceros. Las consultas se hacen directamente a la API de Instagram (Meta), sujeta a sus propias políticas.

Eliminación de datos

Puedes cerrar sesión desde la app para borrar el token del dispositivo. También puedes revocar el acceso desde Instagram en Configuración > Sitios web y aplicaciones. Como no almacenamos tus datos en servidores, no hay más datos que eliminar. Para consultas, escribe a: seb.espi@gmail.com.

Cambios

Si esta política cambia, se actualizará en esta página.
